## 测试方法差异

### PyTorch 版本测试流程

**MatterGen:**
1. 使用 `ChemGraph` 创建测试批次
2. 使用 `collate()` 函数批处理
3. 调用 `model.diffusion_module.model()` 前向传播
4. 测试 10 次，记录输出统计信息
5. 调用 `sampler.generate()` 采样测试

**DiffCSP:**
1. 创建包含 `pos`, `lattice_params`, `atomic_numbers` 的批次
2. 调用 `model(batch, t)` 前向传播
3. 测试 10 次，记录输出统计信息
4. 调用 `model.sample()` 采样测试

## 为什么 PaddlePaddle 缺少 forward/sampling 测试?

### 技术原因

**数据格式差异:**

| PyTorch | PaddlePaddle |
|---------|--------------|
| `ChemGraph` 对象 | `structure_array` 字典 |
| `collate(samples_list)` | `ConcatData` 包装 |
| 直接访问属性 | 通过键访问字段 |

**structure_array 格式示例:**
```python
structure_array = {
    "frac_coords": ConcatData(...),    # 分数坐标
    "cart_coords": ConcatData(...),    # 笛卡尔坐标
    "atom_types": ConcatData(...),     # 原子类型
    "lattice": ConcatData(...),        # 晶格矩阵
    "lengths": ConcatData(...),        # 晶格长度
    "angles": ConcatData(...),         # 晶格角度
    "num_atoms": ConcatData(...),      # 原子数量
}
```

### 实现难点

1. **ConcatData 类**: 需要使用项目自定义的 `ConcatData` 类包装数据
2. **批次索引**: 需要正确创建 `batch_idx` 用于重复采样
3. **数据转换**: 需要将简单 numpy/paddle tensor 转换为正确格式
